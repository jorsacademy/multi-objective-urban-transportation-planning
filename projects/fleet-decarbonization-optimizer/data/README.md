# Local Data Directory

Place the required CSV input files in this directory when running the optimizer locally:

- `demand.csv`
- `vehicles.csv`
- `vehicles_fuels.csv`
- `fuels.csv`
- `carbon_emissions.csv`
- `cost_profiles.csv`
- `sample_submission.csv` (optional)

The original datasets are intentionally not committed to this repository. Check the applicable terms for any dataset before redistributing it.
